# 👤 React Auth Form Practice Project

This project is a **React practice application** that demonstrates how to build reusable login and signup forms using different input-handling strategies.

It showcases:
- Handling forms with `useRef`
- Controlled input with `useState`
- Form submission via `FormData`
- Reusable form components (`Input.js`)
- Validation feedback for better UX
